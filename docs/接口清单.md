## 1. 通用约定

| 项 | 约定 |
|---|---|
| 统一响应 | `ResponseResult<T>`，结构 `{code, errorMessage, data}`，成功 `code=0` |
| 路径前缀 | `/api/{version}/{module}` |
| 网关访问 | `http://<网关>:10000/{小写服务名}/{原路径}`（SCG 服务发现自动路由） |
| 分页请求 | `{page, size, ...条件}` |
| 分页响应 | `{currentPage, pageSize, total, rows: T[]}`（前端取 `PageResult.rows`） |
| 版本策略 | v1 兼容存量，v2 为新契约；新页面一律接 v2 |

### 1.1 前端代理配置

| 前端 | dev 端口 | 代理目标 | 备注 |
|---|---|---|---|
| xftt-app | Vite 默认 | `http://localhost:10000` | 走网关 |
| xftt-wemedia | 8081 | 按路径分流：`/api/v1/media|channel|statistics`、`/login` → :9006 | dev 直连 xftt-media；统一网关后改回 :10000 |
| xftt-admin | 8082 | 按路径分流：`/api/v1/admin`、`/login` → :9007；`/api/v1/channel` → :9003 | dev 直连后端；统一网关后改回 :10000 |

## 7. xftt-admin（平台后台服务，9007）

| 方法 | 路径 | 说明 | 状态 |
|---|---|---|---|
| POST | `/login/in` | 管理员登录 | 已实现 |
| POST | `/api/v1/admin/common/list` | 通用分页查询（`CommonDto`） | 已实现 |
| POST | `/api/v1/admin/common/update` | 通用新增/修改（`model=add|edit`） | 已实现 |
| POST | `/api/v1/admin/common/delete` | 通用删除（`where` 必填） | 已实现 |

**CommonDto 契约（管理端通用 CRUD 唯一入口）**

| 字段 | 类型 | 说明 |
|---|---|---|
| `name` | CommonTableEnum | 业务表枚举名：`AD_CHANNEL` / `AD_SENSITIVE` / `AP_ARTICLE` / `AP_ARTICLE_CONFIG` / `AP_USER` |
| `model` | String | 仅 `update` 接口用：`add` 新增、`edit` 修改 |
| `page` / `size` | Integer | 分页（list 用） |
| `where` | List<CommonWhereDto> | 条件：`{filed, value, type:'eq'|'like'|'between'}` |
| `sets` | List<CommonWhereDto`> | 写入/修改字段集合 |

- `list` 返回体为 `{list: [...], total: N}`（非标准 `PageResult`），前端需映射为 `{rows, total}`。
- 权限由枚举构造参数控制：如 `AP_USER` 仅 `list` 开启，不可新增/修改/删除。
- 此契约已在前端 `xftt-admin/src/api/admin.ts` 对齐（AD-F06）。
