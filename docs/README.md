## 2. 文档命名与写作约定

1. **命名**：中文文档名；需要版本化时用 `-v1` 后缀（如 `接口清单-v1.md`）。
2. **头部元信息**：每篇文档开头必须包含维护者与最后更新日期。
3. **变更标记**：正文中修改处使用 `> 修改点：<说明>` 引用块标注。
4. **交叉引用**：文档间跳转统一使用相对路径，禁止绝对路径与盘符。
5. **状态图例**：已完成 / 进行中 / 待实现 / 有风险。
6. **同步规则**：接口或表结构变更时，必须同日更新 `接口清单.md` 与数据库规范文档，并在 `CHANGELOG.md` 追加记录。
