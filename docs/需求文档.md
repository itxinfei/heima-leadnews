# 心飞头条（xftt）需求文档

> 版本：v1.0　　日期：2026-10-22
> 适用范围：心飞头条项目技术栈升级 + 前后端重构后的全部功能需求基线

---

## 1. 项目背景与目标

心飞头条是一款类"今日头条"的内容资讯平台，包含 APP 用户端、自媒体管理端、平台后台管理端三端，以及内容爬虫、数据迁移、热点计算等后台能力。

本轮改造的两条主线：

1. **技术栈升级**：后端由 Spring Boot 2.x + JDK 8 升级至 **Spring Boot 4.1.1 + JDK 25**；网关升级至 **Spring Cloud 2025.1（SCG 5，前缀 `spring.cloud.gateway.server.webflux`）**；前端由 Vue2/WeEX 老工程重构为 **Vue3 + TypeScript** 新工程。
2. **工程重构**：包名 `com.xinfei` → `com.xftt`，模块命名 `xinfei-leadnews-*` → `xftt-*`，前后端全部迁入新结构。

### 1.1 非功能目标

| 维度 | 要求 |
|---|---|
| 兼容性 | 后端编译与构建在 JDK 25 下零错误；SCG 5 配置按新前缀生效 |
| 可维护性 | 三端前端统一 Vue3 + TS + Vite，类型检查（vue-tsc）纳入构建 |
| 降级能力 | 前端对非核心接口（频道、评论、行为上报）失败静默降级，不阻塞主流程 |
| 安全 | 登录态 JWT；管理端/自媒体端接口鉴权过滤器（AdminTokenFilter 等） |

```
┌──────────┐   ┌─────────────┐   ┌──────────────┐
│ APP 用户端 │   │ 自媒体管理端  │   │ 平台后台管理端 │
│ uni-app   │   │ Vue3+EP     │   │ Vue3+EP      │
│ xftt-app  │   │ xftt-wemedia│   │ xftt-admin   │
└─────┬────┘   └──────┬──────┘   └──────┬───────┘
      └───────────────┼─────────────────┘
                      ▼
        ┌──────────────────────────┐
        │  网关 xftt-gateway:10000  │  SCG5 + Nacos 发现自动路由
        └────────────┬─────────────┘
   ┌─────┬─────┬─────┼─────┬─────┬─────┬─────┐
   ▼     ▼     ▼     ▼     ▼     ▼     ▼     ▼
 login user article behavior media admin crawler images migration
```

### 2.1 模块清单

| 模块 | 职责 | 端口/说明 |
|---|---|---|

| xftt-model | DTO、Pojo、Mapper（MyBatis XML 位于 `model/src/main/resources/mappers/`） | 公共库 |
| xftt-utils | 加解密、JWT、Date、JSON 工具 | 公共库 |
| xftt-apis | 各微服务 Feign 接口定义 | 公共库 |
| xftt-login | APP 端登录注册（JWT） | `/api/v1/login`、`/api/v2/login` |
| xftt-user | 用户中心：关注/粉丝/收藏 | `/api/v1/user/user_follow` |
| xftt-article | 文章列表/详情/搜索/频道/评论/热点 | `/api/v1/article`、`/api/v1/channel`、`/api/v1/comment` 等 |
| xftt-behavior | 行为数据：展示/点赞/不喜欢/阅读 | `/api/v1/behavior/*_behavior` |
| xftt-media | 自媒体端：登录、素材、文章发布、频道管理、统计 | `/api/v1/media/*`、`/api/v1/channel/channels` |
| xftt-admin | 平台后台：通用 CRUD、登录审核、实名认证 | `/api/v1/admin/*` |
| xftt-crawler | CSDN 正/逆向爬虫、IP 代理池、Quartz 调度 | 定时任务 |
| xftt-images | 图片服务：缓存、热点文章配图 | Kafka 消费者 |
| xftt-migration | MySQL→HBase 冷数据迁移、热点文章计算 | Quartz/Kafka |
| service-gateway | 网关 | 10000 |
| service-nacos | 注册/配置中心 | 8848 |
| service-mycat | MyCat 分库分表（含自定义热点分片算法 `XfttBurstRuleAlgorithm`） | 8066 |

## 7. 接口契约约定

- 统一响应：`ResponseResult<T>`，成功 `code=0`；结构 `{code, errorMessage, data}`。
- 统一前缀：`/api/{version}/{module}`；网关经 Nacos discovery locator 按服务名转发。
- 分页协议：请求 `{page, size, ...条件}`；响应 `{currentPage, pageSize, total, rows: T[]}`（前端 `PageResult.rows`）。
- 行为上报路径（xftt-behavior）：`/api/v1/behavior/{show_behavior|like_behavior|unlike_behavior|read_behavior}`；点赞 DTO `{equipmentId, entryId, type, operation}`，operation 0 点赞 / 1 取消。
- 前端代理：app→`http://localhost:10000`（网关）、wemedia→6002、admin→6001。
