# 心飞头条（xftt）需求文档

> 版本：v1.1　　日期：2026-10-24
> 适用范围：心飞头条项目技术栈升级 + 前后端重构后的全部功能需求基线

---

## 1. 项目背景与目标

心飞头条是一款类"今日头条"的内容资讯平台，包含 APP 用户端、自媒体管理端、平台后台管理端三端，以及内容爬虫、数据迁移、热点计算等后台能力。

本轮改造的两条主线：

1. **技术栈升级**：后端由 Spring Boot 2.x + JDK 8 升级至 **Spring Boot 4.1.1 + JDK 25**；网关升级至 **Spring Cloud 2025.1（SCG 5，前缀 `spring.cloud.gateway.server.webflux`）**；前端由 Vue2/WeEX 老工程重构为 **Vue3 + TypeScript** 新工程。
2. **工程重构**：包名 `com.xinfei` → `com.xftt`，模块命名 `xinfei-leadnews-*` → `xftt-*`，前后端全部迁入新结构。

### 1.1 非功能目标

| 维度 | 要求 |
|---|---|
| 兼容性 | 后端编译与构建在 JDK 25 下零错误；SCG 5 配置按新前缀生效 |
| 可维护性 | 三端前端统一 Vue3 + TS + Vite，类型检查（vue-tsc）纳入构建 |
| 降级能力 | 前端对非核心接口（频道、评论、行为上报）失败静默降级，不阻塞主流程 |
| 安全 | 登录态 JWT；管理端/自媒体端接口鉴权过滤器（AdminTokenFilter 等） |

## 7. 接口契约约定

- 统一响应：`ResponseResult<T>`，成功 `code=0`；结构 `{code, errorMessage, data}`。
- 统一前缀：`/api/{version}/{module}`；网关经 Nacos discovery locator 按服务名转发。
- 分页协议：请求 `{page, size, ...条件}`；响应 `{currentPage, pageSize, total, rows: T[]}`（前端 `PageResult.rows`）。
- 行为上报路径（xftt-behavior）：`/api/v1/behavior/{show_behavior|like_behavior|unlike_behavior|read_behavior}`；点赞 DTO `{equipmentId, entryId, type, operation}`，operation 0 点赞 / 1 取消。
- 前端代理：app→`http://localhost:10000`（网关）；wemedia/admin 按路径分流直连服务——`/api/v1/media`、`/api/v1/channel`、`/api/v1/statistics`、`/login`→9006（media），`/api/v1/admin`、`/login`→9007（admin），dev 阶段不经网关。
- 搜索接口（xftt-article）：`/api/v1/article/search/{article_search|associate_search|load_search_history|del_search|clear_search|load_hot_keywords}`，v2 同形；搜索入参 `{searchWords, pageNum, pageSize}`。
- 评论接口（xftt-article）：`GET /api/v1/comment/list?articleId=`、`POST /api/v1/comment/{create,like}`。

| 字号 | 标题 34rpx 加粗 / 正文 30rpx / 元信息 24rpx / Tab 28rpx | 行高 1.4~1.5 |

### 9.2 全局布局框架

**顶栏（Navigation Bar）**：
- 首页顶部为「搜索胶囊 + 红色 Logo/频道」组合：左侧"头条"红底白字标识或搜索图标，中间搜索框（灰底圆角、placeholder"搜你想看的"），右侧「发布/签到」红色按钮。
- H5/App 均为白底黑字导航；沉浸式列表页导航白底。

**频道栏（Channel Tab）**：
- 位于顶栏正下方，sticky 固定；横向滚动，右侧常驻「⊕ 频道管理」入口。
- 选中项：红色文字加粗 + 底部 6rpx 红色短横线（宽度≈文字宽），切换时下划线平滑滑动。
- 未选中：`#222222` 常规字重；频道支持长按拖拽排序、编辑（增删）。

**底部 TabBar**：
- 4~5 个 Tab：首页 / 视频 / （发布⊕）/ 任务 / 我的；当前项目保留「首页 / 我的」两 Tab，发布入口预留。
- 未选中 `#222222`，选中品牌红；图标线性风格，选中填充。

**信息流卡片**：
- 默认单列大图模式（用户可在设置切双列小图）；三种卡片形态：
  1. 右图模式：左侧标题（最多 2 行截断）+ 右侧 220rpx 封面；
  2. 三图模式：标题在上、三张等宽小图横排在下；
  3. 大图模式：标题在上、整幅大图在下。
- 卡片元信息行：作者名（可点，跳作者主页）· 阅读数（"1024阅读"）· 时间（"x分钟前"）· 右侧「×」不感兴趣入口（点击弹出"不喜欢作者/内容质量差/相似内容过多"）。
- 已读标题置灰 `#999999`；广告卡片右下角「广告」角标。

### 9.3 文章详情页

- **头部**：大标题（44rpx 加粗）→ 作者行（头像 + 昵称 + 关注按钮，右侧「关注」红描边小按钮，点击变"已关注"灰底）→ 发布时间 + 阅读数。
- **正文**：富文本，两端对齐，行距 1.8；图片点击全屏预览。
- **相关阅读**：正文尾部"相关推荐"横向卡片列表（3~5 条，缩略图+标题）。
- **评论区**：「全部评论（n）」；每条评论 = 头像 + 昵称/等级 + 内容 + 时间·回复·👍点赞数；作者评论带红色「作者」角标；置顶评论置顶且带角标。
- **底部互动栏（关键交互，完全对齐头条）**：
  - 左侧评论文本框胶囊（灰底全圆角，placeholder"写下你的评论…"），点击从底部滑出输入面板；
  - 依次为：👍点赞（显示数字，激活红色）、⭐收藏、💬评论（点击滚动定位到评论区）、↗分享（点击弹半屏分享面板：微信/朋友圈/微博/QQ/复制链接）；
  - 输入面板：textarea 自动增高 + 表情入口 + 红色「发送」按钮；发送后评论即时插入列表顶部。
- 阅读深度上报：进入页面上报加载/开始阅读，退出上报时长与百分比。

### 9.4 搜索页

- 搜索中间页：历史记录（标签流，可清空）+ 猜你想搜（热词榜，Trie 联想词）。
- 输入即联想（`/associate_search`）；结果页列表样式与信息流一致；无结果空态 + 推荐阅读。

### 9.5 「我的」页

- 顶部红色渐变头部：头像、昵称、头条号 ID；右侧「设置」入口。
- 数据行：关注 / 粉丝 / 获赞，三等分，数字加粗。
- 功能宫格/列表：收藏、历史、下载、作品管理；下方通用列表项（系统设置、意见反馈、退出登录）。
- 未登录态：头像占位 + 「点击登录」红色按钮，功能项点击均先引导登录。

### 9.6 视频频道（预留需求池）

- 双列瀑布流卡片（封面 9:16 + 标题 + 播放量/时长角标）；播放页沉浸式、上滑切换。依赖 BE 端视频资源，暂列 P3。

### 9.7 管理端设计基准（头条号后台风格）

- 参考 mp.toutiao.com 创作者平台：左侧白色导航（Logo 红色高亮 + 当前项红色底 `#FDECEC`）、顶部白色工具栏、内容区浅灰底卡片。
- 数据统计页首屏为指标卡（曝光/阅读/评论/粉丝净增，4 列）+ ECharts 折线趋势图。
- 表格操作列统一「编辑 / 删除」链接式按钮；危险操作红色；批量操作带二次确认。
- 状态以彩色标签呈现：已发布绿、审核中橙、驳回红、草稿灰。

## 10. 逐页 PRD（APP 用户端）

> 每个页面按「布局 → 交互 → 数据 → 边界与空态 → 验收标准」描述，视觉细节遵循第 9 章设计令牌。

### 10.1 首页（pages/index）

**布局**（自上而下）：
1. 顶栏：搜索胶囊（灰底 `#F5F5F5` 全圆角，placeholder"搜你想看的"，左侧 🔍 图标）+ 右侧"发布"红字入口（预留）。
2. 频道栏：sticky 固定，横向滚动，高 88rpx，右缘渐隐遮罩提示可滚动。
3. 信息流：单列卡片，间距 0、卡片间 1rpx 分割线；下拉刷新（白色圆点动画）、触底加载。
4. 加载态：底部"加载中..."；无更多时"—— 没有更多了 ——"。

**交互**：
- 点击频道：高亮切换 + 信息流重置到第 1 页重新拉取；频道切换不保留各频道滚动位置（V1）。
- 点击卡片：整卡可点，跳详情并携带 id；已读卡片标题置灰。
- 下拉刷新完成 showToast "已为你推荐 20 篇"。

**数据**：`POST /api/v1/article/load`，入参 `{page, size:20, channelId}`；响应 `PageResult<ArticleItem>`。

**边界与空态**：
- 接口失败且无缓存：显示空态插画 + "内容加载失败，点击重试"，点击重试。
- 频道列表失败：降级默认频道（不弹错）。
- 无封面图：卡片退化为纯文字模式。

**验收标准**：
- [ ] 首屏 3s 内渲染（含骨架屏）；
- [ ] 触底到加载新数据 ≤ 1s（正常网络）；
- [ ] 频道切换后信息流必须归零并展示所选频道内容；
- [ ] 断网下首页仍可打开并展示降级频道。

### 10.2 文章详情（pages/detail）

**布局**：
1. 标题区：44rpx 加粗标题 → 作者行（头像 64rpx + 昵称 + 右侧「关注」红描边按钮）→ 时间 + 阅读数。
2. 正文：rich-text 富文本，图片可点击全屏预览。
3. 相关推荐：横滑卡片 3~5 条（缩略图 + 单行标题）。
4. 评论区：「热门评论 (n)」；评论项 = 首字头像 + 昵称 + 内容 + 时间/点赞数。
5. 底部互动栏（fixed，含 safe-area）：评论胶囊（点击弹输入面板）、👍 点赞、⭐ 收藏、↗ 分享。

**交互**：
- 关注按钮：未登录跳登录；已登录切换状态并调关注接口。
- 点赞：本地立即翻转 + 红色激活，失败回滚并 toast；上报 `like_behavior`。
- 收藏：翻转 + toast"已收藏/已取消收藏"（上报待接 BE-F10）。
- 分享：H5 复制链接；App 端调 `uni.share` 半屏面板。
- 发评论：底部弹层（textarea 自动增高 + 发送），发送成功关闭弹层、评论插入列表顶部并刷新计数。
- 点赞评论：👍 数字 +1，同一条不可重复（本地去重）。

**数据**：详情 `GET /api/v1/article/{id}`（扁平聚合端点，BE-F11 已实现）；兼容 `POST /api/v1/article/load_article_info`（返回 `{content, article, config}`）；评论 `GET /api/v1/comment/list?articleId=`、`POST /create`、`POST /like`；行为 `/like_behavior`、`/read_behavior`。

**边界与空态**：
- 文章不存在/下架：空态"内容不存在或已删除"。
- 评论为空："抢首评"引导。
- 评论接口失败：评论区显示"评论加载失败"轻提示，正文不受影响。

**验收标准**：
- [ ] 详情打开 ≤ 2s；阅读上报在 onLoad 后异步发出（不阻塞渲染）；
- [ ] 互动栏在 iPhone 底部安全区不遮挡；
- [ ] 点赞操作 200ms 内有视觉反馈；
- [ ] 评论发送后列表即时可见，无需手动刷新。

### 10.3 搜索（已实现，APP-F11/F17）

**布局**：搜索中间页 = 历史标签流（可单删/清空）+ 猜你想搜热词榜（1~10 名）；结果页复用信息流卡片。

**交互**：输入 ≥1 字即联想（防抖 300ms，`/associate_search`，Trie + Redis）；确认搜索写入历史（本地 + 服务端）。

**验收标准**：
- [ ] 联想在 300ms 防抖后触发，连续输入不并发轰炸；
- [ ] 历史最多保留 20 条，超出淘汰最旧；
- [ ] 无结果页提供空态 + 热门推荐。

### 10.4 我的（pages/my）

**布局**：红色渐变头部（`#d43c33 → #a8261d`，135°）= 头像（首字圆形）+ 昵称；数据行关注/粉丝/收藏三等分；菜单列表（收藏/关注/粉丝/浏览历史/退出登录）带右箭头。

**交互**：未登录所有功能项点击先跳登录；数据行点击跳对应列表页（待实现）。

**边界**：未登录头部显示"未登录"+ 引导；接口失败数据行显示"--"。

**验收标准**：
- [ ] 登录后昵称与统计正确回显；
- [ ] 退出登录后回到未登录态且清空本地 token。

### 10.5 登录（pages/login）

**布局**：红色 Logo 块 + "信息创造价值"slogan → 手机号/密码下划线输入 → 全圆角红色登录按钮 → 协议提示。

**交互**：手机号 11 位数字键盘；密码密文 + 可切换明文（待加）；登录成功 `switchTab` 回首页；失败 toast 具体错误信息。

**验收标准**：
- [ ] 空值提交被拦截；
- [ ] token 持久化，杀进程后仍保持登录态；
- [ ] 连续 5 次失败提示"稍后再试"（后端配合）。

## 11. 逐页 PRD（自媒体端与后台管理端）

### 11.1 自媒体端 · 内容管理

- 布局：筛选行（标题输入 + 状态下拉 + 查询按钮）→ 表格（标题/状态标签/创建时间/操作）→ 分页器右下。
- 状态标签配色（9.7）：已发布绿、待审核橙、审核失败红、草稿灰。
- 交互：新建文章（跳编辑器，待实现 WM-F05）；行点击查看详情。
- 验收：标题搜索为模糊匹配；翻页保持筛选条件。

### 11.2 自媒体端 · 发布文章（待实现 WM-F05，P0）

- 布局：标题输入（≤64 字，计数）→ 频道下拉 → 封面上传（单图，从素材库选择或直接上传）→ 富文本编辑器（工具栏：加粗/斜体/标题/图片/链接/视频占位）→ 底部「存草稿」「提交审核」双按钮。
- 交互：提交前敏感词本地预校验（复用敏感词接口）；提交后跳转内容管理并标记"审核中"。
- 数据：`POST /api/v1/media/news/create`（wem_news + wem_news_content 联合提交）。
- 验收：编辑中断开刷新有草稿恢复提示；富文本图片走素材库 URL。

### 11.3 自媒体端 · 素材管理（WM-F06）

- 上传：拖拽/点击上传，图片 ≤5MB，jpg/png/gif；上传成功即入网格（瀑布式）。
- 批量：支持多选删除、全选；删除带确认弹窗。
- 收藏素材：星标，收藏分组置顶。
- 数据：`/api/v1/media/material/{upload_picture, del_picture, list}`。

### 11.4 后台管理端 · 频道/敏感词/用户管理

- 频道管理：新增/编辑弹窗（名称 + 排序 number），删除二次确认；列表按 ord 升序。
- 敏感词管理：新增支持逗号/顿号分隔批量入库；删除确认。
- 用户管理：仅查询（分页 + 用户名模糊）；行内"查看详情"跳用户画像页（待实现）。
- 验收：所有变更操作成功后表格局部刷新；接口 500 显示统一错误 toast 不白屏。

### 11.5 后台管理端 · 审核工作台（AD-F07/F08，P1）

- 布局：顶部 Tab（待审核 / 已通过 / 已驳回，角标计数）→ 列表（标题、来源【自媒体/爬虫】、提交时间、AI 预审结果）→ 详情抽屉（正文渲染 + AI 结论 + 通过/驳回按钮 + 驳回理由必填）。
- 数据：Kafka 审核流（`AutoReviewArticleListener`）+ `/api/v1/admin/common` CRUD。
- 验收：通过/驳回后文章状态实时变更；驳回理由同步通知自媒体端（消息中心，P2）。
